# Changelog

## 1.0.0 (Forge 1.20.1)

First release for Forge 1.20.1 (same features as the NeoForge 1.21.1 version).

- Two rows of tabs on top and two on the bottom
- Drag and drop reordering, across pages, with empty slots and a spare page
- Padlock and "reset all" button (with a confirmation click)
- Merged tabs with a side panel, a "General (A-Z)" entry, reordering, renaming and a configurable number of columns
- Settings saved in `config/tabsorganizer.json`
- English and French translations
